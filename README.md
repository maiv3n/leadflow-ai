# 🚀 LeadFlow AI

Sistema inteligente de qualificação e roteamento de leads usando IA generativa, automação de fluxos e dashboard comercial.

## Stack

- Backend: Node.js + Express
- Frontend: React + TypeScript
- Automação: n8n
- IA: OpenAI API
- Banco de dados: PostgreSQL / SQLite
- Cloud: AWS / Vercel / Railway
- DevOps: Docker + GitHub Actions
